# 용어 사전 — 설계 문서에 나오는 낯선 말들

설계 문서를 읽다가 모르는 단어가 나오면 여기서 찾아보세요. **정확한 정의보다 "감을 잡는 것"에 초점을 맞춘 설명**입니다.

---

## 1. 가장 먼저 알아야 할 5개

| 용어 | 뜻 | 갤러리 K에서는 |
|---|---|---|
| **서버(Server)** | 인터넷 어딘가에 항상 켜져 있는 컴퓨터. 정보를 보관하고, 요청이 오면 답을 준다 | 전시 정보와 회원 정보를 갖고 있는 쪽 |
| **클라이언트(Client)** | 사용자의 손에 있는 것. 스마트폰 브라우저, PC 브라우저 | 관람자의 휴대폰 화면 |
| **프런트엔드(Frontend)** | 눈에 보이는 부분을 만드는 일. 화면, 버튼, 색깔 | 그림 12개가 격자로 놓인 그 화면 |
| **백엔드(Backend)** | 눈에 안 보이는 부분. 정보 저장, 규칙 판단, 로그인 확인 | "오늘 걸어야 할 전시가 무엇인지" 정하는 쪽 |
| **데이터베이스(DB)** | 정보를 표 형태로 차곡차곡 쌓아두는 창고 | 회원 명단, 전시 목록, 그림 정보가 들어 있는 곳 |

> 식당에 비유하면 — **프런트엔드**는 홀(메뉴판, 테이블, 서빙), **백엔드**는 주방(조리, 재료 관리), **데이터베이스**는 냉장고와 창고입니다. 손님(**클라이언트**)이 주문하면 홀이 주방에 전달하고, 주방이 창고에서 재료를 꺼내 만듭니다.

## 2. 데이터베이스 용어

| 용어 | 뜻 | 예 |
|---|---|---|
| **테이블(Table)** | 엑셀 시트 한 장. 같은 종류의 정보를 모아둔 표 | `app_user` 테이블 = 회원 명부 |
| **행(Row) / 레코드** | 표의 가로 한 줄. 정보 하나 | 회원 "김정민" 한 명 |
| **열(Column) / 필드** | 표의 세로 한 칸. 항목 이름 | `name`(이름), `phone`(전화번호) |
| **스키마(Schema)** | 표가 어떻게 생겼는지에 대한 설계도 | "회원 표에는 이름·전화번호·가입일이 있다" |
| **기본키 (PK, Primary Key)** | 각 행을 다른 행과 구별하는 번호. 절대 겹치지 않는다 | 회원마다 붙는 고유 번호 |
| **외래키 (FK, Foreign Key)** | 다른 표의 행을 가리키는 연결선 | 그림 표의 "이 그림은 몇 번 전시 소속" |
| **인덱스(Index)** | 책 뒤의 찾아보기. 원하는 행을 빨리 찾게 해준다 | 없으면 100만 행을 처음부터 다 훑는다 |
| **제약조건(Constraint)** | DB가 강제로 지키는 규칙. 어기면 저장 자체가 거부된다 | "전화번호는 겹칠 수 없다" |
| **UNIQUE(유니크)** | "이 값은 표 전체에서 딱 하나뿐" 이라는 제약 | 같은 날짜에 전시 두 개는 못 만든다 |
| **NULL(널)** | "값이 아직 없음". 0이나 빈 글자와는 다르다 | 아직 안 쓴 그림 설명 |
| **정규화 / 비정규화** | 정보를 쪼개서 중복 없이 두는 것 / 일부러 중복해서 빨리 찾게 하는 것 | 전시 표에 그림 개수를 미리 적어두는 게 비정규화 |
| **열거형(Enum)** | 정해진 몇 개 값 중 하나만 가질 수 있는 항목 | 회원 등급은 `viewer` 아니면 `curator` |
| **UUID** | 전 세계에서 겹치지 않는 긴 무작위 식별 번호 | `550e8400-e29b-41d4-a716-...` |
| **트랜잭션(Transaction)** | 여러 작업을 "전부 성공 아니면 전부 취소"로 묶는 것 | 돈 보내기: 내 계좌에서 빠지고 상대 계좌에 들어가는 게 함께 되거나 함께 안 되거나 |
| **커밋 / 롤백** | 트랜잭션을 확정하는 것 / 없던 일로 되돌리는 것 | |
| **질의(Query) / SQL** | 데이터베이스에게 "이런 정보를 다오"라고 묻는 말과 그 언어 | "오늘 이전에 발행된 전시 중 가장 최근 것" |
| **마이그레이션(Migration)** | 표 구조를 바꾸는 작업을 순서대로 기록해둔 것 | "3번 작업: 전시 표에 숨김 항목 추가" |
| **ORM** | 데이터베이스를 프로그래밍 언어의 말투로 다루게 해주는 도구 | SQLModel이 그것 |
| **시드(Seed) 데이터** | 서비스를 처음 켤 때 미리 넣어두는 기본 정보 | 큐레이터 계정 1개 |
| **낙관적 잠금** | "아마 충돌 안 나겠지" 하고 진행하되, 충돌이 나면 그때 알려주는 방식 | 두 창에서 같은 글을 고칠 때 나중 사람에게 경고 |
| **백필(Backfill)** | 지나간 날짜에 뒤늦게 정보를 채워 넣는 것 | 갤러리 K에서는 **금지**했다 |
| **익명화** | 누구인지 알 수 없게 만들되 기록의 형태는 남기는 것 | 탈퇴한 회원의 방문 기록 |

## 3. API와 통신 용어

| 용어 | 뜻 | 예 |
|---|---|---|
| **API** | 화면과 서버가 정보를 주고받는 **정해진 창구**. "이렇게 물으면 이렇게 답한다"는 약속 | "오늘 전시 알려줘" → 전시 정보 |
| **엔드포인트(Endpoint)** | API 창구 하나하나의 주소 | `/exhibitions/current` |
| **요청(Request) / 응답(Response)** | 화면이 서버에 보내는 것 / 서버가 돌려주는 것 | |
| **HTTP** | 웹에서 요청과 응답을 주고받는 규칙 | |
| **GET / POST / PUT / PATCH / DELETE** | 요청의 종류. 각각 **조회 / 새로 만들기 / 통째로 바꾸기 / 일부만 바꾸기 / 지우기** | |
| **상태 코드(Status Code)** | 응답에 붙는 3자리 숫자 결과 표시 | `200` 성공, `404` 없음, `401` 로그인 필요, `500` 서버 고장 |
| **JSON** | 정보를 주고받을 때 쓰는 글자 형식. `{ "이름": "값" }` 모양 | |
| **봉투(Envelope)** | 모든 응답을 똑같은 겉포장에 담는 방식 | 성공이든 실패든 항상 같은 모양이라 화면 코드가 단순해진다 |
| **페이지네이션(Pagination)** | 목록을 한 번에 다 주지 않고 나눠 주는 것 | 지난 전시 30개를 10개씩 |
| **커서(Cursor)** | "여기 다음부터 주세요"를 표시하는 북마크 | 무한 스크롤에 씀 |
| **캐시(Cache)** | 한 번 받은 것을 잠시 저장해두고 재사용하는 것 | 같은 그림을 매번 다시 내려받지 않는다 |
| **ETag** | "내가 가진 게 최신인가?"를 물어보는 꼬리표 | 같으면 서버가 "그대로 쓰세요"만 답한다 |
| **멱등성(Idempotency)** | 같은 요청을 여러 번 보내도 결과가 한 번 보낸 것과 같은 성질 | 입장 기록을 두 번 보내도 하루 1회로만 센다 |
| **CORS** | 다른 주소의 서버에 요청할 때 브라우저가 거는 안전장치 | 갤러리 K는 같은 주소를 써서 이 문제가 없다 |
| **레이트 리밋 / 스로틀링** | "1분에 몇 번까지만" 하고 요청 횟수를 제한하는 것 | 로그인 5번 틀리면 10분 잠금 |

## 4. 로그인과 보안 용어

| 용어 | 뜻 | 예 |
|---|---|---|
| **인증(Authentication)** | "너 누구야?"를 확인하는 것 | 전화번호 + 비밀번호 |
| **인가(Authorization)** | "너 이거 해도 돼?"를 확인하는 것 | 관리자만 업로드 가능 |
| **세션(Session)** | 로그인한 상태가 유지되는 기간 | 갤러리 K는 90일 |
| **쿠키(Cookie)** | 브라우저가 보관하는 작은 쪽지. 요청할 때마다 자동으로 함께 보내진다 | 로그인 증표 |
| **HttpOnly** | 쿠키를 **자바스크립트가 읽을 수 없게** 막는 설정. 악성 코드가 훔쳐가지 못한다 | |
| **JWT(제이더블유티)** | 위조가 어렵게 서명된 로그인 증표 문자열 | 쿠키 안에 들어 있다 |
| **해시(Hash)** | 원래대로 되돌릴 수 없게 뭉갠 값 | 비밀번호는 해시로만 저장한다 |
| **bcrypt** | 비밀번호 해시에 특화된 방식. 일부러 느리게 만들어 뚫기 어렵게 한다 | |
| **HTTPS** | 오가는 내용을 암호화한 통신 | 주소 앞의 자물쇠 |
| **CSRF** | 사용자가 모르는 사이에 요청이 보내지는 공격 | 헤더 하나를 요구해서 막는다 |
| **XSS** | 악성 스크립트를 화면에 심는 공격 | 남이 쓴 글을 그대로 화면에 넣지 않아 막는다 |
| **CSP** | 브라우저에게 "이 주소에서만 코드를 실행해라"라고 지시하는 규칙 | |
| **마스킹** | 정보 일부를 가리는 것 | `010-****-5678` |
| **감사 로그(Audit Log)** | 누가 언제 무엇을 바꿨는지 남기는 기록 | 관리자가 회원을 차단한 이력 |
| **서명 URL / 서명 쿠키** | "이 사람만, 이 시간까지" 파일을 열 수 있게 하는 임시 열쇠 | 작품 이미지를 아무나 못 보게 |
| **noindex / robots.txt** | 검색엔진에게 "여기는 수집하지 마세요"라고 알리는 표시 | 폐쇄형 서비스라 필수 |

## 5. 클라우드·인프라 용어

| 용어 | 뜻 | 갤러리 K에서는 |
|---|---|---|
| **AWS** | 아마존이 빌려주는 서버·저장소 등의 묶음 | 이 서비스가 올라갈 곳 |
| **서버리스(Serverless)** | 서버를 직접 켜두지 않고, 요청이 올 때만 잠깐 켜지는 방식 | 사람이 적은 서비스에 유리하고 싸다 |
| **Lambda(람다)** | AWS의 서버리스 실행 장치 | 백엔드 코드가 여기서 돈다 |
| **콜드 스타트** | 잠들어 있던 Lambda가 처음 깨어날 때 걸리는 몇 초 | 아침 알림 직후가 문제라 미리 깨워둔다 |
| **Chalice(챌리스)** | 파이썬으로 Lambda 기반 API를 쉽게 만드는 도구 | 백엔드 뼈대 |
| **RDS** | AWS가 대신 관리해주는 데이터베이스 | PostgreSQL을 여기에 둔다 |
| **PostgreSQL** | 데이터베이스 프로그램 이름. 무료이고 튼튼하다 | |
| **RDS Proxy** | 데이터베이스 연결 통로를 아껴 쓰게 해주는 중간 관리자 | 서버리스에서 필수 |
| **S3** | AWS의 파일 창고 | 그림 이미지가 저장되는 곳 |
| **CloudFront / CDN** | 전 세계에 흩어놓은 복사본 서버. 사용자와 가까운 곳에서 파일을 준다 | 그림이 빨리 뜨게 |
| **VPC** | 클라우드 안에 만든 사설 울타리 | 데이터베이스를 밖에서 못 건드리게 |
| **EventBridge / 스케줄러** | "매일 몇 시에 이것을 실행해라"를 관리하는 알람시계 | 아침 알림 발송 |
| **배치(Batch) / 잡(Job)** | 사람 없이 정해진 시간에 도는 정리 작업 | 오래된 기록 삭제 |
| **큐(Queue)** | 처리할 일을 줄 세워두는 대기열 | 알림 발송 대기 목록 |
| **Secrets Manager** | 비밀번호·열쇠를 안전하게 보관하는 금고 | |
| **IaC / Terraform** | 서버 설정을 손으로 클릭하지 않고 글로 적어 관리하는 방식 | |
| **스테이징(Staging)** | 진짜 서비스와 똑같이 만들어둔 연습용 환경 | 배포 전 시험 |
| **배포(Deploy)** | 만든 코드를 실제 서비스에 올리는 것 | |
| **롤백(Rollback)** | 배포한 것을 이전 상태로 되돌리는 것 | |
| **CI** | 코드를 올릴 때마다 자동으로 검사·테스트를 돌리는 장치 | |

## 6. 프런트엔드 용어

| 용어 | 뜻 | 예 |
|---|---|---|
| **React(리액트)** | 화면을 조각(컴포넌트)으로 나눠 만드는 도구 | |
| **컴포넌트(Component)** | 재사용 가능한 화면 조각 | 버튼 하나, 썸네일 하나 |
| **프롭(Props)** | 컴포넌트에 넘겨주는 값 | 버튼에 넘기는 글자 "입장" |
| **상태(State)** | 화면이 기억하고 있는 값. 바뀌면 화면이 다시 그려진다 | 시트가 열렸는지 닫혔는지 |
| **훅(Hook)** | 리액트에서 상태·부수동작을 다루는 함수. 이름이 `use`로 시작한다 | `useCurrentExhibition` |
| **라우팅(Routing)** | 주소(URL)에 따라 어떤 화면을 보여줄지 정하는 것 | `/gallery` → 갤러리 화면 |
| **SPA** | 페이지를 통째로 새로 받지 않고 필요한 부분만 갈아끼우는 웹앱 방식 | 화면 전환이 빠르다 |
| **번들(Bundle) / 청크(Chunk)** | 코드를 하나로 묶은 파일 / 그것을 쪼갠 조각 | |
| **코드 스플리팅** | 지금 필요한 조각만 내려받게 나누는 것 | 관리자 코드는 관람자가 안 받는다 |
| **지연 로딩(Lazy Loading)** | 화면에 보일 때가 되어서야 불러오는 것 | 아래쪽 썸네일 |
| **TypeScript** | 자바스크립트에 "이 값은 숫자다" 같은 표시를 붙인 언어. 실수를 미리 잡아준다 | |
| **Vite(비트)** | 개발 중 화면을 빠르게 띄우고, 배포용 파일을 만드는 도구 | |
| **Tailwind(테일윈드)** | 미리 만들어진 짧은 이름으로 스타일을 입히는 방식 | `p-4` = 안쪽 여백 16px |
| **디자인 토큰** | 색·글자 크기 같은 값에 이름을 붙여 한 곳에서 관리하는 것 | 이름만 바꾸면 전체가 바뀐다 |
| **PWA** | 웹사이트를 앱처럼 홈 화면에 두고 쓸 수 있게 하는 기술 | 갤러리 K가 이 방식 |
| **서비스워커** | 브라우저 뒤에서 도는 작은 프로그램. 오프라인 캐시와 푸시를 담당 | |
| **웹 푸시** | 앱이 꺼져 있어도 오는 알림 | 아침 7시 30분 알림 |
| **VAPID** | 웹 푸시를 보낼 자격을 증명하는 열쇠 한 쌍 | |
| **LQIP** | 아주 작고 흐릿한 미리보기 이미지. 진짜 이미지가 오기 전에 보여준다 | 뿌옇게 보이다 선명해지는 그것 |
| **종횡비(Aspect Ratio)** | 가로:세로 비율 | 미리 자리를 잡아둬야 화면이 안 흔들린다 |
| **LCP** | 화면에서 가장 큰 것이 나타나기까지 걸린 시간 | 2.5초 이내가 목표 |
| **CLS** | 화면이 로딩 중에 덜컥거리며 밀리는 정도 | 0이 목표 |
| **INP** | 눌렀을 때 반응하기까지 걸린 시간 | |

## 7. 코드 구조·품질 용어

| 용어 | 뜻 | 왜 중요한가 |
|---|---|---|
| **아키텍처(Architecture)** | 코드를 어떤 덩어리로 나누고 어떻게 이어붙일지에 대한 큰 그림 | 잘못 잡으면 나중에 고치는 비용이 폭증한다 |
| **계층(Layer)** | 역할별로 나눈 층. 위층은 아래층만 부른다 | 뒤엉키지 않게 |
| **모듈(Module)** | 하나의 역할을 하는 코드 묶음(보통 파일 하나) | |
| **의존(Dependency)** | A가 B를 갖다 쓰는 관계 | 화살표가 한 방향이어야 정리된다 |
| **순환 의존** | A가 B를 쓰고 B가 다시 A를 쓰는 상태 | 어디부터 고쳐야 할지 알 수 없게 된다 |
| **서비스 계층** | 업무 규칙(무엇이 맞고 틀린지)을 판단하는 층 | "12점이 다 차야 발행" 같은 규칙이 사는 곳 |
| **리포지토리 계층** | 데이터베이스에 실제로 묻고 답을 받는 층 | |
| **DTO** | 층과 층 사이에서 정보를 옮길 때 쓰는 단순한 상자 | 비밀번호가 실수로 화면까지 새어 나가는 걸 막는다 |
| **미들웨어** | 모든 요청이 반드시 통과하는 검문소 | 로그 남기기, 로그인 확인 |
| **데코레이터** | 함수 위에 붙여서 기능을 얹는 표시 | "이건 관리자만" |
| **리팩터링** | 동작은 그대로 두고 코드 구조만 정리하는 일 | |
| **린트(Lint)** | 코드 작성 규칙을 자동으로 검사하는 도구 | 사람이 매번 지적하지 않아도 된다 |
| **단위 테스트** | 함수 하나가 제대로 도는지 확인하는 자동 검사 | |
| **통합 테스트** | 여러 부분이 함께 잘 도는지 확인하는 검사 | |
| **E2E 테스트** | 사람이 하듯 화면을 클릭해가며 전체 흐름을 확인하는 검사 | |
| **MSW** | 서버 없이 가짜 응답을 만들어 화면을 시험하는 도구 | |
| **Storybook** | 컴포넌트를 하나씩 따로 띄워보는 전시장 같은 도구 | |
| **시각 회귀 테스트** | 화면 그림을 이전 것과 비교해 달라진 곳을 잡는 검사 | |
| **관측성(Observability)** | 문제가 생겼을 때 무슨 일이 있었는지 알 수 있는 정도 | 로그·지표·경보 |
| **멱등한 배치** | 두 번 돌려도 결과가 같은 정리 작업 | 실수로 두 번 돌아도 안전 |

## 8. 이 프로젝트만의 용어

| 용어 | 뜻 |
|---|---|
| **발행일 (exhibition date)** | 큐레이터가 그 전시를 건 날짜. 전시에 영원히 붙어 다닌다 |
| **관람일 (viewing date)** | 관람자가 보고 있는 오늘 날짜 |
| **연장 (carry-over)** | 오늘 새 전시가 없어서 직전 전시가 그대로 걸려 있는 상태. **고장이 아니라 정상 동작** |
| **백필 금지** | 지나간 날짜에 새 전시를 만들지 못하게 막은 규칙 |
| **이어쓰기 (carry-draft)** | 어제 쓰다 만 원고를 오늘 날짜로 옮겨 마저 쓰는 기능 |
| **발행 (publish)** | 제목·테마·그림 12점이 모두 채워져 관람자에게 보이게 된 상태. 버튼이 없고 자동이다 |
| **숨김 (hide)** | 이미 발행된 전시를 관람자에게서 감추는 유일한 방법 |
| **드래프트 (draft)** | 아직 발행되지 않은, 작성 중인 전시 |
| **휴관 공지** | "며칠까지 쉽니다"를 기간을 정해 걸어두는 안내 |
| **가입 잠금** | 새 회원을 더 받지 않도록 잠그는 스위치 |
| **대행 가입** | 큐레이터가 회원 계정을 대신 만들어 주는 것 (시니어 배려) |
| **큰 글씨 모드** | 글자와 터치 영역을 키우고 그림 격자를 3열에서 2열로 바꾸는 모드 |
| **입장 (entry)** | 갤러리 화면에 들어온 것. **하루에 한 번만** 센다 |
| **P1 / P2 / P3** | 기획서가 정한 세 명의 대표 사용자. P2가 시니어 사용자다 |
| **GAP-1 ~ GAP-20** | 원래 기획에 빠져 있어서 이번에 채워 넣은 항목들의 번호 |
| **RISK-1** | 가장 큰 위험 — "큐레이터가 지쳐서 그만두는 것" |
| **MVP** | 최소한으로 만들어 먼저 내보내는 첫 버전 |
