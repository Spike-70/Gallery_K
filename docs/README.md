```mermaid

    DS["03 디자인 시스템<br/>색·글씨·부품 규격"]
    BE["04 백엔드 아키텍처<br/>서버 코드 구조"]
    FE["05 프런트엔드 아키텍처<br/>화면 코드 구조"]
    UX["06 UX 설계<br/>화면과 동선"]
    CR["07 교차 검토<br/>어긋난 곳 찾기"]

    PRD --> DB --> API
    PRD --> UX --> DS
    API --> BE
    API --> FE
    DS --> FE
    UX --> FE
    BE --> CR
    FE --> CR
    CR -.수정.-> DB
    CR -.수정.-> API
    CR -.수정.-> DS
    CR -.수정.-> UX
```

**변경할 때의 원칙** — 여러 문서에 같은 값이 나오는 경우, 어느 문서가 원본인지는 [07 §4 문서 간 계약 요약](07-CROSS-REVIEW.md#4-문서-간-계약-요약)에 정리되어 있습니다. 원본부터 고치고 참조 문서를 따라가며 맞춥니다.
